Tagline

The incident response agent that remembers what failed and changes the next action.

Builder

Himanshu Kumar · @himanshu748

Project description

Production incidents often outlive the agent session investigating them. When the next responder starts cold, it repeats failed remediation, overlooks operator constraints and wastes the evidence gathered by the previous shift.

Relay is a memory-backed incident response agent that carries operational context across sessions. Its demo follows a checkout latency incident where a stateless responder recommends restarting the service. Relay remembers that the restart already failed, a database restart is blocked until a replica snapshot completes and connection-pool exhaustion is the leading hypothesis. It recommends shifting 20% of traffic to a healthy pool and capturing a pool dump instead.

Sibyl Memory is on the critical path. WARM entity memory stores the incident, hypotheses, constraints and attempted actions. HOT state stores the active incident plus the latest fresh-session receipt. COLD events keep the audit trail. A new session rebuilds the recommendation from recalled state and exposes the exact memories that changed the action. Remove Sibyl and the product falls back to the failed restart.

The working prototype includes a React command interface, FastAPI service, the real sibyl-memory-client local backend and automated tests for recall, persistence plus session continuity. Responders can add live evidence, start a fresh session and verify the resulting journal entries without hidden state.

Next, Relay will add production incident connectors, operator approval gates and evaluation traces across a broader set of remediation scenarios.

Memory implementation note

Relay persists observations, attempted actions, constraints and hypotheses. At fresh-session start it recalls four decision-relevant memories, computes a recommendation and records a visible session receipt. The recalled failed action plus database constraint block unsafe restarts, while the leading hypothesis changes the diagnostic action.
