# Relay, hackathon project summary

Relay is a working Sibyl Memory-backed incident response agent. It demonstrates why durable memory matters by comparing a stateless recommendation with an action changed by recalled failed attempts, hypotheses and operator constraints.

The project includes a React interface, FastAPI backend, real `sibyl-memory-client` local persistence, automated API tests, a 75-second demo script and responsive QA at five viewport sizes.

Run the prototype at [http://127.0.0.1:4173](http://127.0.0.1:4173) while the local servers are active. See the project root `README.md` for setup and demo instructions.
